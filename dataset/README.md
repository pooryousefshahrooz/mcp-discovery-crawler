# MCP server dataset & advertising findings

This folder is a self-contained dataset release. It answers three questions, in order:

1. **What MCP servers do we have, and how did we get them?** → `all_mcp_servers.csv`
2. **Which of those servers actually serve advertisements?** → `ad_servers/`
3. **How did we go from (1) to (2)?** → the pipeline described below.

All data here is derived from read-only measurement. Nothing was purchased, and no destructive
or write tools were ever called. Large raw files (full responses) are kept out of git; every table
here is regenerated by `build_dataset.py`.

---

## 1. The MCP server list — `all_mcp_servers.csv`

**What it is:** one row per MCP **server endpoint we connected to and successfully enumerated**
(i.e. we spoke the MCP handshake and asked it to list its tools). Columns:

| column | meaning |
|---|---|
| `host` | the server's hostname |
| `endpoint` | the full MCP endpoint URL we talked to |
| `status` | result of enumeration (`complete` = we got its tool list) |
| `server_name`, `server_version` | what the server reports about itself |
| `n_tools` | number of tools the server exposes |
| `n_prompts`, `has_instructions` | other MCP capabilities it advertises |
| `listed_in_directories` | how many public directories listed this endpoint (1–5) |
| `directory_sources` | which directories (official registry / Glama / Smithery / MCP.so / MCP Directory) |
| `auth_stated` | whether the directory listing said auth is required |
| `transports` | transport(s) advertised (streamable-http, sse, …) |

**How we got it (discovery):** we crawled **five public MCP directories** on 2026-09-30 —
the official MCP Registry, Glama, Smithery, MCP.so, and MCP Directory — through their APIs or
public sitemaps (`directories/collect.py`, `directories/merge.py`). Deduplicating their listings by
endpoint gave **~32,840 distinct MCP endpoints**. We then **connected to each endpoint** and ran the
MCP handshake + `tools/list` (`fresh_measurement/`), which is what populates this CSV. Servers that
required authentication or were unreachable have `status` ≠ `complete` and `n_tools = 0`.

**Exact counts (this run, 2026-10-29 enumeration of the 2026-09-30 discovery):**

| | endpoints |
|---|---:|
| Discovered across the 5 directories (deduplicated) | **32,838** |
| …that **exposed their tool list** (`n_tools ≥ 1`) | **7,011** (119,090 tools) |
| …fully enumerated, read-only probe allowed (`status = complete`) | 5,218 |
| …listed a tool schema but we skipped calling (priced-tool signal) | 1,334 |
| Required authentication | 13,046 |
| Initialize/transport error or unreachable | ~12,700 |

So the CSV has **all 32,838 discovered endpoints** (so the population is auditable), and you can
filter to the **7,011 enumerable servers** with `n_tools >= 1`. The advertising analysis in (2)
starts from those reachable, tool-exposing servers. Directory coverage: most endpoints (23,694) were
listed by a single directory; 9,064 appeared in two or more — the directories are largely
complementary, so merging all five is what gives full coverage.

## 2. The advertising servers — `ad_servers/`

**What it is:** the subset of servers from (1) that we confirmed **serve advertisements** inside
their tool results — i.e. a tool call returns a sponsored/paid item, an affiliate link, or an
ad-auction result, not just ordinary content.

- **`ad_servers/ad_servers_summary.csv`** — one row per ad-serving server:
  host, endpoint, the specific **ad-serving tool(s)**, tool category (shopping / web_search /
  ad_network / …), number of distinct ads and ad impressions we observed, the coders' confidence
  and basis, total tools on the server, and an example advertised URL.
- **`ad_servers/<host>.md`** — a one-page profile per ad server containing:
  - the endpoint and server identity,
  - **the ad-serving tool(s) and the evidence** for why it is advertising
    (e.g. "Amazon affiliate tag minted by the server", "response disclosure: store links are
    affiliate links, only paying stores listed"),
  - **example advertised items / links** actually returned,
  - **the full list of tools the server exposes, with each tool's description.**

## 3. How we went from the full list to the ad servers (the pipeline)

```
 (A) DISCOVER            (B) ENUMERATE               (C) PROBE                  (D) CODE / CONFIRM
 5 public directories -> connect + tools/list   ->  call read-only search/    -> detect ad signatures,
 (official, Glama,       on every endpoint          recommendation tools on      two independent coders
 Smithery, MCP.so,       = all_mcp_servers.csv      servers whose metadata or    label each as ad / not,
 MCP Directory)                                     tools suggest commerce;      record origin & evidence
       |                        |                   record every response        = ad_servers/
   ~32.8k endpoints        enumerated servers        (read-only, >=2.5s gap,
                           with tools                 never buy/sign-up)
```

- **(A) Discover** — crawl the five directories → merge/dedup → endpoint list.
  Code: `directories/`. 
- **(B) Enumerate** — connect to each endpoint, MCP handshake + `tools/list`, store tools and
  schemas. Code: `fresh_measurement/` collector. Output here: **`all_mcp_servers.csv`**.
- **(C) Probe** — for servers whose tools look commercial (search / shopping / recommendation),
  call those **read-only** tools with benign queries and record the full responses. Safety: no
  purchases, logins, or sign-ups; links are not followed; ≥2.5 s between calls; stop on rate-limit.
  Code: `ad_probe/`, recorded responses in `analysis/ad_provenance/out/responses.jsonl`.
- **(D) Code / confirm** — a detector flags ad "signatures" (sponsored labels, affiliate params,
  ad-auction fields, affiliate-network links); **two independent coders** then label each signature
  as advertising or not and record its origin (operator vs upstream) and the evidence
  (inter-coder agreement κ ≈ 0.91 on the 4-way label). Code: `analysis/ad_provenance/`
  (`s2_detect_candidates.py` → `s6_adjudicate.py` → `s7_quantify.py`). Output here: **`ad_servers/`**.

So: **`all_mcp_servers.csv` is the population; `ad_servers/` is the confirmed advertising subset,
reached by probing the commercial-looking servers and having two people confirm the ads.**

## Regenerate everything

```
python3 dataset/build_dataset.py
```

Reads only existing recorded data (`fresh_measurement/`, `directories/`, `analysis/ad_provenance/`)
and rewrites `all_mcp_servers.csv` and `ad_servers/`.

## Provenance of the numbers

The advertising confirmation (who coded, agreement, evidence) is documented in
`analysis/ad_provenance/` (codebook + final adjudicated codes). The directory crawl and enumeration
are in `directories/` and `fresh_measurement/`.
